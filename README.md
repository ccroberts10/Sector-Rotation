# Sector Rotation Scanner

A standalone daily scanner with a **web dashboard** that ranks the 11 SPDR sector ETFs by relative strength vs SPY, computes a biotech-specific rotation signal, classifies the market regime, maps your SIGNAL watchlist to position sizing buckets, and generates an AI recap of the day's findings.

Designed to run continuously on Railway as its own service. Zero npm dependencies, zero SIGNAL coupling.

## Dashboard

Visit your deployed Railway URL (e.g. `https://your-service.up.railway.app/`) to see:

- **Risk regime banner** (when actionable) — bright TAKE RISK OFF or CAUTION alert at the top
- **Capitulation banner** (when actionable) — BOUNCE SETUP or OVERSOLD alert signaling time to put risk back on
- **AI recap** — Claude-generated 2-3 sentence read incorporating risk regime AND capitulation
- **Risk regime panel** — defensive composite, XLY/XLP momentum, SPY trend (with 50/200DMA and VIX), velocity divergence
- **Capitulation watch panel** — McClellan Oscillator (NYMO), TRIN (Arms Index), Put/Call ratio with thresholds
- **Regime classification** — RISK-ON / RISK-OFF / MIXED with leaders and laggards
- **SIGNAL sizing buckets** — every watchlist ticker mapped to size-up / normal / trim / skip
- **Action items** — rotation-into and rotation-out alerts based on rank shifts
- **Biotech read** — XBI/SPY and XBI/IBB ratios with confirmation logic
- **Full rankings** — all 11 sectors ranked by composite RS with 1w/1m/3m breakdowns
- **Rank shifts** — sectors that moved 3+ positions vs the prior run
- **Manual trigger** — click "Run Scan" to fetch fresh data on demand

## Two complementary verdicts

The scanner runs two parallel detection layers that answer different questions:

**Risk regime — "Should I take risk OFF?"** Uses defensive composite, XLY/XLP momentum, SPY trend, VIX, and velocity divergence. Best at catching the start of multi-week drawdowns. Verdict: TAKE RISK OFF / CAUTION / NEUTRAL / RISK-ON CONFIRMED.

**Capitulation watch — "Should I put risk back ON?"** Uses NYMO (McClellan Oscillator), TRIN (Arms Index), and CBOE Put/Call ratio. Best at catching washed-out market bottoms when fear is extreme. Verdict: BOUNCE SETUP / OVERSOLD / WATCH / NEUTRAL.

The two signals are independent. When BOTH fire — risk regime says TAKE RISK OFF and capitulation says BOUNCE SETUP — that's the classic capitulation bottom setup. Sell-off is real, but exhaustion is confirmed.

## Risk regime signals (the four early-warning detectors)

1. **Defensive composite** — average rank of XLP, XLU, XLV, XLRE. When defensives skew into the top half (avg ≤ 5.5), institutional money is quietly de-risking. Triggers EMERGING RISK-OFF at ≤5.5, STRONG RISK-OFF at ≤4.
2. **XLY/XLP momentum** — consumer discretionary vs staples ratio. The cleanest "risk on/off" gauge in markets. Negative 1-month change = consumer caution = risk-off tell.
3. **SPY trend overlay** — price vs 50DMA and 200DMA, classifies as UPTREND / CORRECTION / RECOVERY / DOWNTREND. Combined with VIX level (COMPLACENT < 15, CALM < 20, ELEVATED < 25, FEAR < 30, PANIC ≥ 30) for the regime call.
4. **Velocity divergence** — flags sectors where 1-week RS has clearly broken from the 1-month trend. A sector like XLK with 1w deeply negative while 1m still positive is showing early breakdown velocity — the rotation hasn't shown up in the rankings yet, but it's coming.

The four signals combine into a single **risk verdict score**. At score ≥7 the verdict is **TAKE RISK OFF**, at ≥4 it's **CAUTION**, at ≤-2 it's **RISK-ON CONFIRMED**.

## What it tells you

- **AI recap** (2-3 sentences) at the top of each alert — plain-English read on what the rankings mean for the trading day, generated by Claude
- **Regime card** — classifies the day as RISK-ON / RISK-OFF / MIXED and gives per-ticker SIGNAL sizing buckets (size up / normal / trim / skip) for your watchlist
- **Sector rankings** — which sectors are leading and lagging the broad market (composite RS over 1-week, 1-month, 3-month windows)
- **Biotech read** — whether biotech is rotating in (XBI outperforming SPY across timeframes, with XBI/IBB confirming risk-on speculative flow vs defensive pharma)
- **Rank shifts** — flags any sector that moved 3+ positions vs the last run

## Composite RS formula

```
composite = (1wk RS × 0.20) + (1mo RS × 0.50) + (3mo RS × 0.30)
```

Tilted toward 1-month for actionable rotation signals. Adjust weights in `sectorRotation.js` if you want different responsiveness.

## Biotech signal logic

| Condition | Signal |
|-----------|--------|
| XBI/SPY 1mo > 0 AND 3mo > 0 AND XBI/IBB 1mo > 0 | **ROTATION IN** |
| XBI/SPY 1mo > 0 AND XBI/IBB 1mo > 0 | EARLY POSITIVE |
| XBI/SPY 1mo < 0 AND 3mo < 0 | STILL OUT |
| Otherwise | NEUTRAL |

XBI/IBB matters because XBI is equal-weight small/mid-cap biotech and IBB is cap-weighted (large pharma-adjacent). When XBI outperforms IBB, that's risk-on speculative biotech money — usually the real rotation signal, not just defensive healthcare bid.

## Setup

### 1. Push to a new GitHub repo

```bash
cd sector-rotation
git init
git add .
git commit -m "Initial commit: sector rotation scanner"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sector-rotation.git
git push -u origin main
```

### 2. Create a new Railway service

1. Railway dashboard → **New Project** → **Deploy from GitHub repo** → select `sector-rotation`
2. Railway will detect Node.js automatically and run `npm start`
3. Add environment variables in **Variables** tab:
   - `TRADIER_TOKEN` — your Tradier production token (same one SIGNAL uses)
   - `PUSHOVER_TOKEN` — your Pushover application token
   - `PUSHOVER_USER` — your Pushover user key
   - `ANTHROPIC_API_KEY` *(optional)* — enables AI recap. Get one at console.anthropic.com
4. (Optional) Add a **Volume** mounted at `/data` so the snapshot persists across redeploys. If you skip this, the first run after every redeploy will say "no prior snapshot" — alerts still work, just no shift detection until run #2.

### 3. Test it

Once deployed, hit the public URL Railway gives you:

- `GET /` — status page (last run date, schedule)
- `GET /healthz` — JSON health check
- `POST /run` — trigger a scan immediately

Or set `RUN_ON_BOOT=true` temporarily and redeploy to force one run.

## Local testing

```bash
cp .env.example .env
# fill in your tokens
node sectorRotation.js   # one-shot scan
node index.js            # run the scheduler
```

## Files

- `sectorRotation.js` — core scanner (data fetch via Alpaca + Yahoo, RS math, alert pipeline)
- `riskRegime.js` — defensive composite, XLY/XLP gauge, SPY trend overlay, velocity divergence, master verdict
- `capitulation.js` — NYMO, TRIN, CBOE Put/Call ratio, bounce-setup verdict
- `regimeAdjustment.js` — static rule engine that maps rankings to SIGNAL sizing buckets
- `aiRecap.js` — Claude API call for plain-English daily recap (incorporates both risk regime and capitulation)
- `index.js` — scheduler + HTTP server (dashboard, /api/latest, /run, /healthz)
- `public/index.html` — single-page web dashboard (self-contained, no build step)
- `package.json` — Node 18+, no dependencies (uses built-in `https`, `http`, `fs`)

## Notes

- **No npm dependencies.** Uses only Node built-ins. Faster cold starts, smaller surface, fewer supply-chain concerns.
- **Tradier rate limits.** 14 requests per scan with 150ms spacing — well under any limit.
- **Snapshot file.** Stored at `/data/sectorRotationSnapshot.json` if Railway volume is mounted, otherwise in the working directory (will reset on redeploy).
- **First-run behavior.** No rank-shift detection on the very first run — needs a prior snapshot to compare against.
